Welcome to Show Mode

Instead of a regular song queue, the queue is now organized by singer — each with their own queue of up to 5 songs, in automatic rotation.

1 Click "Load Music" (or drag a file) — you'll be asked which singer this song is for. Type a new name to create the singer on the spot.
2 Repeat for each song/singer of the night. The rotation order follows the order you added them.
3 Hit play — the system takes care of moving to the next singer on its own. To edit names, reorder, or add more songs later, use "Manage Singers" in Settings.
